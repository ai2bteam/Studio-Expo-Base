# Expo App

Built with [Expo](https://expo.dev) SDK 55, React Native 0.83, and TypeScript.

## Getting Started

```bash
npm install
npx expo start --web
```

## Project Structure

- `app/` — File-based routes (Expo Router)
- `components/` — Reusable UI components
- `constants/` — Theme colors and config
- `assets/` — Fonts and images
